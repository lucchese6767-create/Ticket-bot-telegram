# Telegram Ticket Bot

## Arquivos
- bot.py
- requirements.txt
- render.yaml

## Configuração
No Render, adicione as variáveis:
BOT_TOKEN = token recebido no @BotFather
SUPPORT_GROUP_ID = ID do grupo de suporte

Não publique seu BOT_TOKEN.

## Execução local
pip install -r requirements.txt
python bot.py
